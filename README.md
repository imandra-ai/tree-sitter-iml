# tree-sitter-iml

Tree-sitter grammar for [IML](https://docs.imandra.ai/imandrax/)

- Based on [tree-sitter-ocaml](https://github.com/tree-sitter/tree-sitter-ocaml) with additional grammar support for IML-specific structures.
- IML grammar extensions are in `grammars/iml/`
- Example IML files can be found in `iml_examples/`
- Related project: see [iml-query](https://pypi.org/project/iml-query/) for programmatic manipulation of IML.
